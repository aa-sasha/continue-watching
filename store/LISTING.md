# Карточка в Chrome Web Store — что куда вставлять

Архив: `anime-tracker-store.zip` (сборка `dist/store`, `node scripts/build.mjs`).

## Вкладка «Описание» (Store listing)

**Название** (из манифеста): Продолжить просмотр — трекер серий

**Краткое описание** (из манифеста, 120 из 132 символов):
Запоминает серию и момент, где вы остановились на сайтах с видео, и возвращает к ним в один клик. Данные — только у вас.

**Подробное описание:**

```
Смотрите сериалы на разных сайтах и забываете, на какой серии остановились? «Продолжить просмотр» запоминает это за вас.

Как это работает
• Откройте сайт, где смотрите видео, и нажмите в окне расширения «Отслеживать этот сайт». Chrome спросит доступ только к этому сайту.
• Включите серию. Расширение запомнит сезон, серию и минуту, на которой вы остановились.
• В окне расширения — список «Продолжить просмотр»: что смотрели, где остановились и сколько серий осталось. Нажмите на сериал — откроется его страница, а видео продолжится с того же места.
• Досмотрели серию — в списке сразу появится следующая.
• Номер серии определился неверно — поправьте его кнопками ‹ › рядом с записью.

Приватность
• Расширение работает только на сайтах, которые вы добавили сами. Убрать сайт можно в любой момент — доступ к нему вернётся Chrome.
• История хранится только на вашем устройстве. Ничего не отправляется ни нам, ни третьим лицам; аналитики и рекламы нет.
• Расширение ничего не меняет на сайтах и в плеерах — только читает, на каком месте видео.
```

**Категория:** Развлечения (Entertainment)
**Язык:** русский

**Графика:**
- Значок 128×128 — в архиве (`icons/icon128.png`)
- Скриншоты 1280×800 — `store/screenshot-1.png`, `store/screenshot-2.png`
- Маленькая промо-плитка 440×280 — `store/promo-440x280.png`

## Вкладка «Конфиденциальность» (Privacy practices)

**Единственное назначение (Single purpose):**
Запоминать, на какой серии и минуте пользователь остановился в видео на выбранных им сайтах, и возвращать его к этому месту.

**Обоснование разрешений:**

| Разрешение | Обоснование |
|---|---|
| `storage` | История просмотра (сериал, серия, минута) и список отслеживаемых сайтов хранятся локально в chrome.storage на устройстве пользователя. |
| `activeTab` | Когда пользователь открывает окно расширения, нужно узнать адрес текущей вкладки, чтобы предложить «Отслеживать этот сайт» или показать, что сайт уже отслеживается. |
| `scripting` | 1) Подключить скрипт трекера только к сайтам, которые пользователь добавил сам (registerContentScripts). 2) Узнать адреса окон видеоплеера на текущей вкладке после действия пользователя: плеер часто встроен с другого домена, и доступ к нему запрашивается вместе с сайтом. |
| Доступ к сайтам (`optional_host_permissions`) | Необязательный, запрашивается отдельно для каждого сайта в момент нажатия «Отслеживать этот сайт». Нужен, чтобы читать текущее время и номер серии стандартного видеоэлемента `<video>` на этом сайте. Без нажатия у расширения нет доступа ни к одному сайту. |

**Удалённый код:** Нет, удалённый код не используется. Весь код — в пакете расширения.

**Использование данных:** не отмечать ни одного типа данных — расширение ничего не собирает и не передаёт с устройства. Отметить все три подтверждения:
- не продаю и не передаю данные третьим лицам, кроме разрешённых случаев;
- не использую и не передаю данные для целей, не связанных с единственным назначением;
- не использую данные для оценки кредитоспособности или кредитования.

**Политика конфиденциальности (URL):** https://aa-sasha.github.io/continue-watching/privacy.html — GitHub Pages из `docs/` ветки `main`. Ссылка на claude.ai не подошла: страница приватная и собирается скриптом, проверяющий её не видит (отказ «Purple Nickel», 12.10.2026).
